# Aroma Flow

Система інтернет-магазин кавово-чайної продукції з адміністративною панеллю та каталогом товарів.

## Технології

- **Backend:** Node.js, Express, Mongoose, JWT, MongoDB
- **Frontend:** React 18, React Router, Vite, Axios
- **Database:** MongoDB
- **Architecture:** REST API + SPA (Single Page Application)

## Можливості

### Покупець (Клієнтська частина)
- Перегляд каталогу кавово-чайної продукції з поділом на категорії
- Перегляд детальної сторінки окремого товару
- Додавання товарів до кошика та управління кількістю (глобальний стан)
- Оформлення замовлень та авторизація/реєстрація профілю

### Адміністратор (Адмін-панель)
- Перелік та управління користувачами системи
- Контроль і перегляд оформлених замовлень
- Управління каталогом товарів

## Встановлення та запуск

### Вимоги
- Node.js 18+
- MongoDB 6+ (локальна або хмарна база даних)

### Автоматичний запуск (через скрипт)
У головній папці проєкту ви можете використати файл запуску `start.bat`, який автоматично налаштує і запустить обидві частини проєкту.

### Ручний запуск

#### Бекенд (Server)

```bash
cd server
npm install
npm start
```

#### Frontend (Client)

```bash
cd client
npm install
npm run dev
```

Додаток буде доступний за адресою: http://localhost:3000

## Структура проекту
 
 ```
/client
  /public
    /assets           # Статичні ресурси (картинки товарів)
  /src
    /api              # Axios клієнти (авторизація, замовлення, товари)

    main.jsx          # Точка входу React
    styles.css        # Загальні стилі

/server
  /controllers        # Логіка контролерів (auth, product, order, admin)
  /models             # Схеми даних MongoDB (User, Product, Order)
  /routes             # API маршрути (auth, products, orders, admin)
  server.js           # Головний файл сервера (Express, підключення до MongoDB)
  .env                # Змінні середовища
  package.json        # Залежності бекенду
  ```

## Ключові особливості

### Аутентифікація та Безпека
- Реєстрація та безпечний вхід користувачів (JWT)
- Розподіл ролей (Покупець / Адміністратор)

### Кошик та Замовлення
- Додавання товарів до кошика в реальному часі (з використанням глобального стану)
- Швидке оформлення замовлень кавово-чайної продукції

### Адміністрування
- Зручне управління каталогом товарів через адмін-панель
- Перегляд та контроль замовлень користувачів

## API Endpoints

### Авторизація (`/api/auth`)
- `POST /api/auth/register` — Реєстрація користувача
- `POST /api/auth/login` — Вхід в систему

### Товари (`/api/products`)
- `GET /api/products` — Отримання списку товарів
- `GET /api/products/:id` — Деталі конкретного товару

### Замовлення (`/api/orders`)
- `POST /api/orders` — Створення нового замовлення

### Адмін-панель (`/api/admin`)
- `GET /api/admin/users` — Список користувачів
- `GET /api/admin/orders` — Список усіх замовлень для адмінки
